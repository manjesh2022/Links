# 🔗 Links

A simple, clean, and mobile-friendly personal links dashboard for organizing and managing your favorite links in one place.

## ✨ Features

- 📂 Organize links into categories
- 🔍 Search links quickly
- ➕ Add new links
- ✏️ Edit existing links
- 🗑️ Delete links
- 🏷️ Automatic link type detection
- 🗂️ Automatic category detection
- 😀 Automatic emoji/icon suggestions
- 📱 Mobile-friendly responsive UI
- 🌙 Dark-themed interface
- 🔗 Open links in a new tab
- 💾 Save links using browser `localStorage`
- 📤 Export links as a JSON backup
- 📥 Import links from a JSON backup
- 🔄 Reset saved links
- 🖱️ Hidden scrollbars while keeping scrolling enabled

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage
- Responsive Web Design
